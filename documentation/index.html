DRIVEFORGE Template Documentation

DRIVEFORGE is an editorial-grade, production-quality website template designed for vehicle sales resource platforms, automotive training academies, and dealership sales enablement hubs.

Core Stack
HTML5, Bootstrap 5.3.3, CSS3 Variables, Vanilla JS, GSAP.
Dual Themes
Native Light & Dark themes with localStorage and OS preference sync.
Zero Bloat
No React/Vue build step needed. Works straight out of the box.

3. Design Tokens & Colors

All visual tokens are defined via CSS custom properties in assets/css/style.css. To customize the brand accent, modify the --accent-amber variables: 

:root {
  /* Automotive Amber Accent System */
  --accent-amber: #f57c00;
  --accent-amber-hover: #ff9800;
  --accent-amber-active: #e65100;
  --accent-amber-soft: rgba(245, 124, 0, 0.12);
  --accent-amber-glow: rgba(245, 124, 0, 0.28);
  --accent-blue: #2563eb;
}

4. Typography & Fonts

DRIVEFORGE leverages three distinct typefaces via Google Fonts to achieve an authoritative editorial-automotive balance:

  • Space Grotesk: Display headings, large titles, card headers, and numeric stats.
  • Inter: Body text, navigation elements, metadata tags, and interactive form controls.
  • DM Serif Display: Selective editorial quotes and philosophical callouts.

5. Dark Mode Implementation

The theme switcher is managed in assets/js/main.js. It checks for a saved theme in localStorage, falls back to the operating system's prefers-color-scheme, and applies the data-bs-theme attribute on the <html> element.

6. JavaScript Interactions

The vanilla JS module in main.js encapsulates several key functionalities:

  • Live Search Engine: Triggers with keyboard shortcut / or Ctrl+K. Offers instantaneous autocomplete suggestions.
  • Dynamic Filtering & Sorting: Instant client-side filtering on resources.html, video-tutorials.html, and templates.html without page reloads.
  • Modal Video Player: Reusable lightbox simulating scenario video lessons with interactive controls.
  • File Download Simulation: Triggers mock sample downloads with toast notification feedback.
  • Live Community Submission: Validates the discussion form and immediately prepends the new post to the top of the discussion feed.
  • Bookmark Toggle: Saves/removes resources with instant toast feedback.

7. SEO & Accessibility

Every page includes semantic HTML5 landmarks (<header>, <nav>, <main>, <article>, <footer>), skip-to-content links, visible keyboard focus indicators, accessible ARIA attributes, and Open Graph tags.
